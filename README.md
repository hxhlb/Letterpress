# Letterpress

[now-on-havoc]: https://havoc.app/package/letterpress

[<img width="150" src="https://docs.havoc.app/img/badges/get_square.svg" />][now-on-havoc]

An awesome music visualizer “tweak” that based on TrollStore floating window technology.  
Compatible with iPhone from **iOS 15** to 17.0 with TrollStore.

## Features

- Special particle effects at the top of screen.
- Suits the notch or the Dynamic Island.
- Match the colors of album artworks.
- Display CJK characters in lyrics of now playing songs.
- Text segmentation for Indo-European languages (e.g. English).
- *Too hard to recognize?* Use **accessory label** to get a clear view of lyric contents.

## Lyrics Supports

You can try using the following plugin to sync the lyrics of the now playing track to the Media Controls.

- ✅ Apple Music: [AMLyrics](https://github.com/Lessica/AMLyrics/releases)
- ✅ Spotify: [EeveeSpotify (Lessica Fork)](https://github.com/Lessica/EeveeSpotify/releases)
- ✅ YouTube Music: [YTMusicUltimate (Lessica Fork)](https://github.com/Lessica/YTMusicUltimate/releases)
- ✅ QQ Music
- ✅ Netease Cloud Music
- ✅ Kugou Music
- ✅ Kuwo Music
